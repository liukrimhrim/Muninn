# Local decision tracker

Start with [the design map](map.md). Research lives in `research/`; throwaway experiments live in `spikes/`. One file per decision lives in `issues/`.

Status is `open`, `claimed`, or `resolved`. An unresolved, unassigned ticket is takeable only when every ID in `Blocked by` is resolved. Scan by numeric filename order. `Assignee` records the claimant. Local comments and resolutions append under `## Comments` and `## Answer` respectively; the map holds only a short linked index of resolved answers.

This tracker is local. Nothing here has been posted to an external service.
